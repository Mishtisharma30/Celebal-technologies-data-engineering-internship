## Week 6 - Spark Architecture and Data Processing

### Objective

Understand Spark architecture and perform efficient data processing using PySpark DataFrames.

### Tasks Performed

* Studied Spark architecture including Driver, Cluster Manager, and Executors.
* Learned Spark execution modes and Lazy Evaluation.
* Explored DAG (Directed Acyclic Graph) and Spark fault tolerance.
* Read and worked with data using Spark DataFrames.
* Applied filtering and column selection operations.
* Renamed columns and performed data type casting.
* Created new columns using DataFrame transformations.
* Handled null values and filtered datasets efficiently.
* Explored wide transformations and shuffle operations.
* Compared CSV and Parquet file formats.
* Learned Predicate Pushdown and Spark performance optimization concepts.
* Built simple data processing workflows using Spark DataFrames.

* Apache Spark
* PySpark
* Python
* Jupyter Notebook
