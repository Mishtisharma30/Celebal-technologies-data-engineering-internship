# Week 4 - Azure Data Engineering Pipeline

## Objective

Learn Azure cloud concepts and build an end-to-end data pipeline using Azure Storage and Azure Data Factory.

## Dataset

Superstore Sales Dataset from kaggle:
https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

## Work Completed

* Created a Resource Group in Azure.
* Created a Storage Account and Blob Container.
* Uploaded the dataset to Azure Blob Storage.
* Created and configured Azure Data Factory (ADF).
* Configured Linked Services and Datasets.
* Used the Get Metadata activity to retrieve file information.
* Built a pipeline using the Copy Data activity.
* Executed and monitored the pipeline.
* Assigned IAM roles and configured access permissions.
* Validated successful data movement from source to destination.

## Azure Concepts:

* Resource Groups
* Storage Accounts
* Blob Storage
* Azure Data Factory
* Linked Services
* Datasets
* Get Metadata Activity
* Copy Data Activity
* IAM Roles
