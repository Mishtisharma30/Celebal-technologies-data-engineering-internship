## Objective

Perform data exploration, data cleaning, transformation, and basic Delta Lake operations using PySpark in Databricks.

## Dataset

- Sample Superstore Dataset

## Tasks Performed

- Loaded the CSV dataset into a PySpark DataFrame.
- Explored the dataset by displaying the first and last 5 rows.
- Checked the dataset schema, row count, column names, and data types.
- Identified and handled missing values.
- Removed duplicate records.
- Filtered records based on sales.
- Selected relevant columns for analysis.
- Created derived columns (`Unit Price` and `total_amount`).
- Saved the cleaned dataset as a CSV file.
- Saved the cleaned dataset in Delta format.
