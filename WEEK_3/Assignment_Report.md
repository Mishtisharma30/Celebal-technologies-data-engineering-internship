# Week 3 - Advanced SQL Analysis

## Objective

Analyze sales data using SQL by applying Subqueries, CTEs, and Window Functions to solve business problems and generate insights.

## Dataset

Superstore Sales Dataset from kaggle:
https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

## Work Completed

* Loaded the dataset into a SQL database.
* Created separate tables for customers, orders, and products.
* Inserted data using `SELECT DISTINCT`.
* Used subqueries to identify above-average sales and highest-value orders.
* Applied CTEs to calculate customer-wise sales summaries.
* Used Window Functions (`ROW_NUMBER`, `RANK`) for ranking and analysis.
* Combined JOINs, CTEs, and Window Functions to generate customer sales rankings.
* Solved business queries such as:

  * Top customers
  * Low-performing customers
  * Single-order customers
  * Above-average sales analysis

## SQL Concepts Practiced

* Subqueries
* Common Table Expressions (CTEs)
* JOINs
* ROW_NUMBER()
* RANK()
* Aggregate Functions
* GROUP BY
* ORDER BY
