# Week 2 - SQL Data Analysis

## Objective

Analyze sales data using SQL by applying filtering, aggregation, and business queries to generate useful insights.

## Dataset

Superstore Sales Dataset from kaggle:
https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

## Work Completed

* Loaded the dataset into a SQL database.
* Explored the table structure and sample records.
* Applied filters using `WHERE` clauses.
* Used `GROUP BY` and aggregate functions to analyze sales data.
* Identified top products, categories, and customers.
* Analyzed monthly sales trends.
* Checked for duplicate records and validated data quality.

## SQL Concepts Practiced

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* LIMIT
* SUM, AVG, COUNT
* HAVING

## Skills Learned

* SQL querying
* Data filtering
* Aggregation and analysis
* Business insight generation
* Data validation
